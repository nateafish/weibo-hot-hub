作为“十五五”时期的万亿级战略部署，“六张网”建设正加速推进，今年相关领域的投资规模预计将超过7万亿元，各项核心数据与标志性工程持续刷新进度条。 [人民网](https://m.weibo.cn/detail/5335833902055899) [华夏时报](https://m.weibo.cn/detail/5321085499476197) [央视财经](https://m.weibo.cn/detail/5321003093983600) [CCTV焦点访谈](https://m.weibo.cn/detail/5329018247448887)

[红妖苏姐](https://m.weibo.cn/detail/5311589349067690)

### 一、投资规模与战略定位
- **年度投资**：2026年，“六张网”及相关重点领域建设的投资规模预计超**7万亿元**，是稳增长、扩内需的关键之举。 [华夏时报](https://m.weibo.cn/detail/5321085499476197) [人民网](https://m.weibo.cn/detail/5335833902055899) [财联社APP](https://m.weibo.cn/detail/5301321919628035)
- **“十五五”规划**：仅新型电网与城市地下管网两张网，未来五年的投资就将分别超过**5万亿元**，带动约10万亿元的市场规模。 [中国新闻网](https://m.weibo.cn/detail/5301342843179163) [红妖苏姐](https://m.weibo.cn/detail/5311589349067690) [央视财经](https://m.weibo.cn/detail/5310459425327845)
- **核心目标**：这既是传统基础设施补短板，也是新型基础设施建设的发力点，旨在夯实中国式现代化的战略底座。 [人民网](https://m.weibo.cn/detail/5335833902055899) [中国新闻网](https://m.weibo.cn/detail/5301342843179163)

[人民网](https://m.weibo.cn/detail/5335833902055899)

### 二、六张网建设进度速览
| 网络名称 | 核心进展与数据 |
| :--- | :--- |
| **水网** | 国家水网覆盖**80.3%** 的国土面积；南水北调东、中线一期工程累计向北方调水超**892亿**立方米，惠及**1.95亿**人口。 |
| **新型电网** | 截至2026年6月底，全国累计发电装机容量达**40.4亿**千瓦；“十五五”将推动西电东送规模达4.2亿千瓦以上。 |
| **算力网** | 截至7月底，全国智能算力规模达**240万PFLOPS**；八大国家算力枢纽节点已建成智算总规模占全国比重超80%。 |
| **新一代通信网** | 5G-A商用网络覆盖超**330个**城市；第一阶段6G技术试验已顺利完成。 |
| **城市地下管网** | “十五五”时期将继续建设改造约**77万公里**管网，涵盖燃气、排水、供水等。 |
| **物流网** | 2026年上半年全国社会物流总额**181.1万亿元**，同比增长5.1%；2025年快递业务量约1990亿件，连续12年居世界第一。 |

### 三、标志性工程最新动态
- **水运提能级**：平陆运河已实现全线通水，预计2026年9月通航；三峡水运新通道工程也已正式开工，将迎来新一轮运力大跃升。 [CCTV焦点访谈](https://m.weibo.cn/detail/5329018247448887) [华夏时报](https://m.weibo.cn/detail/5321085499476197)
- **算力与能源协同**：广东阳江总投资超1100亿元的吉瓦级海底算力中心正加速建设；藏粤直流特高压工程紧锣密鼓推进，可将西部清洁电力“跨省闪送”直达广东，仅需9毫秒。 [华夏时报](https://m.weibo.cn/detail/5321085499476197)
- **通信技术突破**：国内首个Pre6G试验网投入运行，通信能力跃升10倍。 [华夏时报](https://m.weibo.cn/detail/5321085499476197)
