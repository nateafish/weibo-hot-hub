一场由欧洲国家主导的“黄金回家”潮正在加速，荷兰、法国近期接连将存放于美国的黄金大规模转移或清零。 [红星资本局](https://m.weibo.cn/detail/5339801471681785) [央视新闻](https://m.weibo.cn/detail/5339334455592350) [央视财经](https://m.weibo.cn/detail/5339830236220669)
### 一、多国央行集体行动，储备格局生变
- **荷兰大幅调整**：2026年3月至8月，荷兰央行将约86吨黄金从纽约和渥太华转移至伦敦，其在纽约的存放比例从31.3%降至18.5%。 [环球时报](https://m.weibo.cn/detail/5338964262913145) [央视财经](https://m.weibo.cn/detail/5339084786501899)
- **法国全部撤回**：2025年7月至2026年1月，法国以“金融置换”方式清空了存放于纽约近百年的129吨黄金，实现全部2437吨黄金储备100%本土化。 [央视新闻](https://m.weibo.cn/detail/5339334455592350) [央视财经](https://m.weibo.cn/detail/5339830236220669)
- **德国持续施压**：德国已在2013至2017年从美国运回674吨黄金，但目前仍有约1236吨存放在纽约，国内要求加速回迁的政治呼声日益高涨。 [立一在香港](https://m.weibo.cn/detail/5339019976115607) [红星资本局](https://m.weibo.cn/detail/5339801471681785)
### 二、欧洲各国回迁规模与重点转移
| 国家 | 关键行动与储备变化 |
| --- | --- |
| 荷兰 | 将86吨黄金从美、加转移至伦敦，降低对美依赖 |
| 法国 | 清零在美黄金，全部2437吨储备集中于本土 |
| 德国 | 已运回674吨，仍有1236吨在美，面临回迁压力 |
| 土耳其 | 2018年将存放于美国的220吨黄金全部运回本土 |
| 奥地利 | 2015至2018年完成90吨黄金回迁 |
| 波兰 | 2019年从伦敦运回100吨黄金 |
| 印度 | 海外存放比例从2023年的约55%降至2026年的约22% |

 [央视财经](https://m.weibo.cn/detail/5339830236220669) [红星资本局](https://m.weibo.cn/detail/5339801471681785) [环球时报](https://m.weibo.cn/detail/5338964262913145)
### 三、迁徙驱动因素
- **资产主权安全**：俄乌冲突后，俄罗斯约3000亿美元海外资产被冻结，各国央行担心海外黄金成为地缘博弈的“人质”，优先将控制权掌握在自己手中。 [环球时报](https://m.weibo.cn/detail/5339704154655335) [央视新闻](https://m.weibo.cn/detail/5339334455592350)
- **美元信用弱化**：美国联邦债务突破40万亿美元，美元长期信用受质疑。黄金已成为全球最大官方储备资产，占全球央行储备的27%，超越美债的22%。 [小六忠诚](https://m.weibo.cn/detail/5339820473720248)
- **危机流动性考量**：荷兰央行明确表示，将黄金转移至伦敦是因为该市场流动性更强，便于在极端危机情况下实现快速交易，而在纽约则可能面临交割障碍。 [环球时报](https://m.weibo.cn/detail/5338964262913145) [央视财经](https://m.weibo.cn/detail/5339494779719944)
