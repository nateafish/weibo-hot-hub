2026年9月20日起，新修订的《住房公积金管理条例》正式施行，公积金提取场景**从原先的6种拓展至9种**，将装修、物业费等直接纳入法定可提范围。
新政的核心变化是公积金定位从“购房专用”转向覆盖“租、购、修、养”全生命周期，这并非简单的数量增加，而是对居民居住需求的系统性回应。 [人民日报](https://m.weibo.cn/detail/5345154705658565) [毒科技](https://m.weibo.cn/detail/5345191699418629) [七月梅子青](https://m.weibo.cn/detail/5345199054130723) [广元日报看广元](https://m.weibo.cn/detail/5345194639885185) [皮皮推](https://m.weibo.cn/detail/5345197225411239) [甜菜咻](https://m.weibo.cn/detail/5345192268008794) [琦瑜啊_](https://m.weibo.cn/detail/5345185820050666) [小怡说车](https://m.weibo.cn/detail/5345244575172469) [瓶盖说](https://m.weibo.cn/detail/5345338091113236) [北京日报](https://m.weibo.cn/detail/5345126368938707) [厚恩投资张延昆](https://m.weibo.cn/detail/5345193010398885) [谯华](https://m.weibo.cn/detail/5345188718578909) [成都市中级人民法院](https://m.weibo.cn/detail/5345242522058817) [小王来电](https://m.weibo.cn/detail/5345244002650922) [四川日报](https://m.weibo.cn/detail/5345254324571409) [吉安发布](https://m.weibo.cn/detail/5344610231519061) [央视财经](https://m.weibo.cn/detail/5344496403351052)
### 一、新增三项消费类提取场景
- **装修自住住房**：缴存人装修自有住房可按规定提取公积金。各地额度与频次不同，例如兰州规定夫妻合计上限10万元、10年可提一次，西安上限20万元。
- **支付物业费**：物业费纳入法定提取范围。各地年度上限各异，如兰州每人每年最高5000元，惠州每人每年2400元，多地要求凭发票实报实销。
- **兜底条款**：新增“经国务院批准的其他住房消费情形”，为未来加装电梯、适老化改造新需求预留了制度空间，保证政策的灵活性。 [中国蓝新闻](https://m.weibo.cn/detail/5345260081518658)
### 二、租房提取门槛彻底取消
原条例中“房租超出家庭工资收入规定比例”的限制被删除。现在只要在缴存地无房且实际租房，即可申请提取公积金支付房租，大幅降低了新市民与青年人的租房减负门槛。 [北京日报](https://m.weibo.cn/detail/5345126368938707) [是曦苒a](https://m.weibo.cn/detail/5345407171559839)
### 三、九项法定提取情形全对比
以下是调整前后的完整对比，清晰展示“6变9”的具体内容。

| 调整后（9项） | 调整前（6项） | 变化说明 |
| :--- | :--- | :--- |
| 1. 支付房租 | 1. 房租超出家庭工资收入的规定比例 | 取消收入比例门槛 |
| 2. 购买、建造、翻建、大修自住住房 | 2. 购买、建造、翻建、大修自住住房 | 保留 |
| 3. 偿还购房贷款本息 | 3. 偿还购房贷款本息 | 保留 |
| **4. 装修自住住房** | - | **新增** |
| **5. 支付自住住房物业费** | - | **新增** |
| 6. 离休、退休 | 4. 离休、退休 | 保留 |
| 7. 完全丧失劳动能力并与单位终止劳动关系 | 5. 完全丧失劳动能力并与单位终止劳动关系 | 保留 |
| 8. 出境定居 | 6. 出境定居 | 保留 |
| **9. 国务院批准的其他住房消费情形** | - | **新增（兜底条款）** |
