体检报告上血压130-139/80-89mmHg，以前叫“正常高值”，在2026版国际高血压指南中已被**改为“血压升高”**，明确这不再是接近正常的健康状态。 [中国新闻网](https://m.weibo.cn/detail/5368076191403668) [头条新闻](https://m.weibo.cn/detail/5368150520763893) [凯恩斯](https://m.weibo.cn/detail/5368159968171392) [阿笨汽车观察](https://m.weibo.cn/detail/5368189479293133) [缥杪](https://m.weibo.cn/detail/5368160792349152) [银子堆成山](https://m.weibo.cn/detail/5368177234284793) [风云梦远](https://m.weibo.cn/detail/5368189006645635) [炫梓-深圳成都南京北京上海全勤](https://m.weibo.cn/detail/5368190397844756) [懒虫兜里有财](https://m.weibo.cn/detail/5368147710575844) [你的香菜拌饭](https://m.weibo.cn/detail/5368152294950066) [当你未眠时](https://m.weibo.cn/detail/5368155564412967) [医疗圈那点事](https://m.weibo.cn/detail/5367966126311981) [财入门](https://m.weibo.cn/detail/5368167960150285) [晏秋秋](https://m.weibo.cn/detail/5367965894837493) [小鱼渡劫](https://m.weibo.cn/detail/5368151592405158) [极客小c](https://m.weibo.cn/detail/5368187287506229)
### 一、新旧分级一表对比
| 分类 | 收缩压/舒张压 （mmHg） | 核心变化 |
| :--- | :--- | :--- |
| **正常血压** | ＜130 / ＜80 | 理想状态 |
| **血压升高** （新） | 130～139 / 80～89 | 旧称“正常高值”，现为需干预的预警区间 |
| 1级高血压 | 140～159 / 90～99 | 诊断标准未变 |
| 2级高血压 | ≥160 / ≥100 | 诊断标准未变 |

### 二、改名背后的医学逻辑
- **风险已被证实**：血压在130-139/80-89mmHg区间时，血管与器官的损伤已在累积。研究显示，该区间人群的肾功能恶化风险比血压低于120mmHg者高出**20%**，且大脑衰老速度更快。 [江西应急管理](https://m.weibo.cn/detail/5368207005192922)
- **“正常”二字易致忽视**：旧称“正常高值”容易让人误以为“还正常，不用管”，从而错失通过生活方式逆转的最佳干预窗口期。改名旨在敲响警钟，推动关口前移。 [银子堆成山](https://m.weibo.cn/detail/5368177234284793) [凯恩斯](https://m.weibo.cn/detail/5368159968171392) [o小茗銅學o](https://m.weibo.cn/detail/5368174677590549) [医疗圈那点事](https://m.weibo.cn/detail/5368133113094315) [缳徉](https://m.weibo.cn/detail/5368179729632842) [予晴暖秋](https://m.weibo.cn/detail/5368189989163459) [行远Henry](https://m.weibo.cn/detail/5368214169062543)
### 三、诊断红线未变，不等于要吃药
- **高血压诊断标准仍是≥140/90mmHg**：指南并未下调诊断门槛，“血压升高”不等于确诊高血压病。 [连锋医生](https://m.weibo.cn/detail/5368145473702682)
- **首选非药物干预**：处于该区间，若无合并高危疾病，优先通过限盐、减重、规律运动等生活方式调整，多数人不必立即用药。若生活方式干预3个月后仍不达标，再由医生评估是否用药。 [肿瘤专科医生](https://m.weibo.cn/detail/5367981584421353) [芝能-烟烟](https://m.weibo.cn/detail/5368154278068251) [海妍味饼干my](https://m.weibo.cn/detail/5368157619622363)
